Enhanced Zomato Dataset Analysis
Overview

This project analyzes restaurant data from the Enhanced Zomato Dataset to uncover insights about customer behavior, pricing trends, and restaurant performance across major Indian cities. The dataset includes detailed information about cuisines, prices, ratings, and popularity, enabling data-driven exploration of the food and hospitality industry. The analysis uses SQL and Python for querying, data transformation, and insight generation.

Dataset Description

The dataset consists of 123,657 rows and 26 columns, covering restaurant names, cuisines, cities, prices, ratings (dining and delivery), votes, and popularity metrics. It provides a balanced mix of categorical and numerical data suitable for descriptive and comparative analytics. Each row represents an item or restaurant-level record reflecting customer feedback and service quality.

Objectives

Analyze restaurant performance and customer ratings.

Compare dining and delivery experiences.

Identify top-rated and most popular restaurants.

Study price–rating relationships and city-level trends.

Derive insights for business improvement and customer engagement.

Technologies Used

Python (Pandas, NumPy) – Data cleaning and preprocessing

SQL – Querying and data analysis

Power BI / Tableau – Data visualization and dashboard creation

Excel – Data verification and review

GitHub – Version control and documentation

Steps Performed

Loaded and cleaned the dataset to handle missing and inconsistent values.

Created a database and structured table for SQL queries.

Executed analytical SQL queries to explore cuisine, rating, and pricing trends.

Aggregated and visualized data to identify key restaurant and city-level patterns.

Derived business insights and summarized findings for decision-making.

Key Insights

Delhi, Bangalore, and Hyderabad have the highest restaurant density.

North Indian, Chinese, and Fast Food are the most common cuisines.

Dining ratings are generally higher than delivery ratings.

Highly rated restaurants often maintain mid-range pricing for better value.

Expensive dishes are concentrated in metro cities, reflecting luxury dining trends.

Popular chains gain large vote counts due to brand trust and consistent service.

SQL Analysis Summary

Fifteen SQL queries were used to extract and interpret insights, covering operations such as:

Viewing distinct cuisines

Identifying top-rated and most expensive items

City-wise aggregation of restaurants

Analyzing pricing and popularity correlations

Filtering based on customer ratings and affordability

Conclusion

The Enhanced Zomato Dataset Analysis provides valuable insights into India’s food service industry by examining restaurant pricing, ratings, and popularity. The findings reveal that customer satisfaction depends on balanced pricing, quality service, and strong brand presence. This project demonstrates how structured data analytics can guide restaurant owners and delivery platforms toward better market positioning and improved customer experience.
